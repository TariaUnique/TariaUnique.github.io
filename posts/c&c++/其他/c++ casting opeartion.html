c++ casting opeartion

  • reinterpret_cast 用于指针类型的强制转换，编译器不做任何检查或调整。 通过用于两个完全不相关的类型的强制转换。 如果存在层级关系，使用static_cast, dynamic_cast

    int* p = new int(65);
char* ch = reinterpret_cast<char*>(p)

  • dynamic_cast 用于指向层级结构的多态类型的指针和引用向下转换，编译器会做运行时检查。

    Base *b = new Base;
if (Derived * d = dynamic_cast<Derived*>(b)){
  //...
}

    如果检查通过，转换会成功，否则失败，指针类型的转换返回nullptr,引用类型的转换抛出异常 也可向上转换，但没有必要，还浪费运行时资源

dynamic_cast 通常用于多态类类型的转换上，这是因为它依赖于运行时类型信息（RTTI），只有具有虚函数的类才会生成 RTTI 信息。如果一个类没有虚函数，那么它不支持多态，dynamic_cast 在转换时可能无法正常工作，因为它依赖于 RTTI 来确定对象的实际类型。

不过，从技术角度来说，dynamic_cast 并不局限于只能在具有多态性质的类上使用，你可以在任何类类型上使用 dynamic_cast，但是如果没有虚函数，那么 dynamic_cast 的行为会退化成 static_cast，即它不会进行运行时的类型检查，而是简单地按照编译时的类型信息进行检查调整，这时使用 dynamic_cast 就没有意义了，因为这样不会提供任何额外的安全性保障。

dynamic_cast一般用于向下转换，但向上转换也是可以的

  • const_cast 用于给被转换对象添加或去除const限定

    const int c = 10;
int* w = const_cast<int*>(&c);

  • static_cast 相比于dynamic_cast，在运行时做类型检查，static_cast做的是编译期检查，因此其检查的消耗比dynamic_cast小。 通常用于隐式类型转换（比如派生类的指针或引用转换为基类的指针或引用，也就是向上转换，也可用于向下转换，但前提是自己得知道被转换的指针/引用的实际指向，否则虽然static_cast可以编译通过，但运行时可能会出错）。 当然如果使用static_cast做向下转换代替dynamic_cast,其代码是可以编译通过的，只是不安全，因为转换可能本该是失败的。 在static_cast转换时，编译器会根据静态类型做指针的相应调整

任何类型的指针可以隐式转换为void, void 应该使用static_cast转换为具体类型的指针。 两个毫不相关的类型的指针之间的强制转换，应该使用reinterpret_cast,这是最不安全的转换

实例： 现有如下全局类型和对象

class A { public: virtual ~A(); /*...*/ };
A::~A() { }
class B : private virtual A { /*...*/ };
class C : public A { /*...*/ };
class D : public B, public C { /*...*/ };

A a1; B b1; C c1; D d1;
const A a2;
const A& ra1 = a1;
const A& ra2 = a2;
char c;

For each of the following C-style casts, write the equivalent new-style cast. Which are incorrect if not written as a new-style cast?

void f()
{
A* pa; B* pb; C* pc;

//pa = const_cast<A*>(&ra1);
pa = (A*)&ra1;
//可以写成pa = const_cast<A*>(&a2); 可是因为a2本身是const 对象，我们通过const_cast强行去掉指针的const属性，后续通过该指针修改a2会出错，undefined behavior,anything could happen。 const_cast一般用于添加const属性
pa = (A*)&a2;
//只能写成 reinterpret_cast<B*>(&c1),B和C是两个不相关的类型，只能这样强制转换
pb = (B*)&c1;
//这里的C-stype 转换是错的，C-style转换没有指针的调整
//在C++, C是D的public base,不需要转换，C++编译器会自动调整。当然也可以使用static_cast
pc = (C*)&d1;
}

l

Critique each of the following C++ casts for style and correctness.

void g()
{
//这里只能使用reinterpret_cast做指针类型的强制转换。 char和unsigned char， char和signed char 之前并没有相关关系，只能使用reinterpret_cast强制转换
unsigned char* puc = static_cast<unsigned char*>(&c);
signed char* psc = static_cast<signed char*>(&c);

//这里可以直接隐式转换
void* pv = static_cast<void*>(&b1);
//this is okay
B* pb1 = static_cast<B*>(pv);
//没必要转换
B* pb2 = static_cast<B*>(&b1);
//可以const_cast,因为a1本身不是const的
A* pa1 = const_cast<A*>(&ra1);
//不应该const_cast, 后续通过pa2修改a2会出问题
A* pa2 = const_cast<A*>(&ra2);
//这里dynamic_cast返回nullptr,因为c1不是B,也没有继承B.如果想要转换有效，不返回nullptr,唯一使用的转换是reinterpret_cast
B* pb3 = dynamic_cast<B*>(&c1);
//返回nullptr,B是private 继承A, B is-not-an A
A* pa3 = dynamic_cast<A*>(&b1);
//okay, but unnecessary
B* pb4 = static_cast<B*>(&d1);
//should use dynamic_cast
//但这里使用static_cast也是可以的。这里使用static_cast意味着你明确知道被转换的类型的实际指向，编译器会直接返回指针值
D* pd = static_cast<D*>(pb4);
//pb2实际指向的是B对象，B和A之间是private 继承关系，dynamic_cast返回nullptr
pa1 = dynamic_cast<A*>(pb2);
//pb4实际指向D对象，D和A之间是public继承关系，这里的转换okay
pa1 = dynamic_cast<A*>(pb4);
//okay,指针有调整
C* pc1 = dynamic_cast<C*>(pb4);
//throw bad_cast exception
C& rc1 = dynamic_cast<C&>(*pb2);
}

dynamic_cast的转换是运行时检查指针/引用的实际指向的，当然如果没有RTTI信息，就退化为static_cast了，只能编译期根据声明的类型检查。

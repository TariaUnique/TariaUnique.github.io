characters in c++

c++ 提供了四种字符类型：char, wchar_t, char16_t, char32_t;

char,一个字节，常用来表示ASCII字符集的字符

wchar_t, 它的字节数在不同的系统上不一样，linux上是4个字节，windows上不清楚

char16_t, 2个字节

char32_t, 4个字节

我们在初始化这些字符变量的时候，通常对于不同的编码方式，有不同的前缀,L,u,U

char     a =  '0';        
wchar_t  b = L'我';       
char16_t c = u'我';       
char32_t d = U'我';

或者

char     a =  '\x30';       
wchar_t  b = L'\uFFEF';       // \u是16位 unicode point 的unicode escape
char16_t c = u'\u00F6';    // \u是16位 unicode point 的unicode escape    
char32_t d = U'\U0010FFFF';   // \U是32位 unicode point 的unicode escape

没有前缀的，应该使用的是IDE默认的编码规则，通常都是UTF-8 L前缀的，it creates a wide character literal. The encoding is implementation-defined, typically UTF-32 on Unix-like operating systems， windows不清楚，UTF-16 or UTF-32吧 u前缀的，使用UTF-16编码，但只能用于unicode code point 在 U+0000 to U+FFFF 范围的字符 U前缀的，使用UTF-32编码

unicode 字符集的码点有21位，支持1,114,112 characters， 其码点from 0x000000 to 0x10FFFF

UTF-32 is a fixed-length encoding, where each Unicode code point is encoded to a 4-byte number. It's a direct mapping, so a unicode code point U+12345(hex) would be encoded to a 32-bit number 0x00012345 in UTF-32.

UTF-16 编码，是变长编码，要么需要2字节，要么需要4字节。Unicode code points U+0000 to U+FFFF (the Basic Multilingual Plane) are encoded to a single 16-bit code unit in UTF-16，是简单的映射 。 而 code points from U+10000 to U+10FFFF 被编码为4字节number,不是简单的映射

UTF-8 也是变长编码，使用1-4字节。同时backwards compatible with ASCII.也就是ASCII字符的编码和UTF-8的编码结果是一样的，都只是一个字节。

现在UTF-8是各平台默认支持的编码规则了，我们在linux下输入locale,可以查到当前终端默认使用的编码规则。同时，基本上IDE也都是默认使用的UTF-8。

在使用std::cout输出各种字符串时，需要注意字符串的编码规则和终端的解码规则要一致，否则可能是乱码

string的类型是basic_string<char>,当我们使用

std::string str = "你好，世界";
std::cout<<str<<std::endl;

"你好，世界"这个字符串被IDE使用UTF-8编码，虽然string中存储的是char，但这些char就是UTF-8编码的byte sequence,所以，只要我们的terminal也是UTF-8解码的，都可以正常输出字符串

如果我们使用如下UTF32编码字符串

std::wstring str = L"你好，世界";// wstring应该就是basic_string<wchar_t>
std::wcout<<str<<std::endl;

因为终端使用的是UTF-8解码，所以输出的是乱码,这时候只能转换为UTF-8编码才行

std::wstring str = L"你好，世界";
std::wstring_convert<std::codecvt_utf8<wchar_t>> conv;
std::string utf8_string = conv.to_bytes(str);
std::cout << utf8_string << std::endl;

注意

char32_t cccc= '我'; //UTF8编码
char32_t cccc = U'我';//UTF32编码

char32_t dddd = '\U0010FFFF';//UTF8编码
char32_t dddd  = U'\U0010FFFF'; //UTF32编码，dddd的byte sequence 就是 0x0010ffff

这两个byte sequence 是完全不一样的

utf8的编码规则，也很简单，1字节的就跟ascii一样，2-4字节的，最高位几个1就代表几个字节，最高位几个1之后跟个0，其余字节首位是10 比如是3个字节，那么就是1110 xxxx , 10xx xxxx, 10xx xxxx. 除了符号位之外的xxxxxxxxxxxxxxxx就是unicode 码点。（貌似是这个规则，没有查，只是简单回忆下）所以utf8编码，如果不是编码ascii字符的话，编码后的byte sequence,如果被转为整数, 比如转换为4字节整数，这4个字节就不能再被UTF8解码了。

输出单个字符的时候，只有ASCII字符可以直接在终端显示，其他字符都会输出成数字

std::cout<<'a'<<std::endl; //输出 a

std::cout<<'我'<<std::endl; //输出 int 值

这是因为cout在输出字符串时，实际上接收的const char* 指针，对该指针指向的byte sequence 不会做改变。

而在输出单个字符时，接收的是字符的值，ASCII字符的utf8编码只有一个字节，首位是0，直接被当成整数值接收（1字节整数值），这个值也可被终端的UTF-8解码为ascii字符显示。而非ASCII字符，通常为1-3个字节，需要转换成整数，如果转换成int就是4个字节，不管首位填充什么，这4个字节就不能再被UTF8解码了,终端只能输出int值

所以要输出非ASCII字符，将单引号改成双引号

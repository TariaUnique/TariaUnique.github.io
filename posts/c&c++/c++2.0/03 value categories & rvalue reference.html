03 value categories & rvalue reference

expression（表达式）

An expression is a sequence of operators and their operands, that specifies a computation. (an operator with its operands, a literal, a variable name, a function call etc.)

Expression evaluation may produce a result (e.g., evaluation of 2 + 2produces the result 4) and may generate side-effects (e.g. evaluation of std::printf("%d", 4) prints the character '4' on the standard output).

Each C++ expression is characterized by two independent properties: A type and a value category. Each expression has some non-reference type, and each expression belongs to exactly one of the three primary value categories: prvalue, xvalue, and lvalue.

在c++11之前，表达式的value category 只有两种 rvalue,lvalue. c++11因为引入了移动语义，所以又细分了xvalue出来。

以c++11标准之前举例：

  • 10的type是int,是 rvalue
  • int i = 0;, i的type也是int, 它是lvalue。
  • int & li=i, li的type是int(表达式的type是non reference的),是lvalue
  • int && ri = 10, ri的type也是int，也是lvalue.(任何变量都是lvalue,任何函数的参数都是lvalue. ri是个右值引用，可以引用右值。但ri自己又是个左值。这在函数参数传递时会出现问题。所以c++11又搞出了std::forward专门解决这个问题)
  • static_cast<int&&>(li) 这个函数调用的返回值是rvalue.(c++11中叫做xvalue)
  • 假设某函数Widget getWidget(), 该函数调用后的返回值是rvalue.
  • 假设某函数Widget& getWidget(Widget& ),该函数调用后的返回值是lvalue.
  • 假设某函数Widget&& getWidget(Widget& ),该函数调用后的返回值是rvalue.(c++11中叫做xvalue)
  • li+ ri 该表达式的type是int,value 是rvalue

rvalue reference

c++11中有左值引用，右值引用，模板参数中还有万能引用。 左值引用,可以引用左值表达式，不能引用右值表达式。 但是const左值引用可以引用右值表达式，但不能更改右值。 右值引用，只能引用右值表达式，不能引用左值表达式。

以上所说的左值，在c++11中，指的是lvalue. 右值，指的是prvalue和xvalue.

事实上，在c++11之前是没有右值引用的。也就是在c++11之前，我们在代码中是无法操作右值的，最起码无法更改右值。在C++11引入右值引用之前，右值只能存在于右值表达式中，通常这个表达式求得的值是临时对象，其结果通常在表达式计算完成后就销毁了。引入右值引用之后，右值的生命期和右值引用关联，即使表达式已经计算完了，其结果可以依然一直存在直到其右值引用的生命期结束。比如我们可以写如下代码

string Hello()
{
    return “Hello”;
}
string &&rvalRef = Hello(); //这里使用右值引用了函数的返回值，这个返回值是临时对象。
rvalRef += “ World”; //更改了这个临时对象的值

value catetory

before c++11

在c++11之前，表达式的value category只有两种，rvalue和lvalue. (也就是所谓的right hand side 和 left hand side)

lvalue, 这个表达式求得的值明确的指向某个对象或者函数（designates a function or an object）.

  • 变量 i int i = 10
  • 指向对象的指针 int * pi=&i
  • 指向函数的指针 void(*pf)(int i) = func
  • 表达式*pi或者*pf,也就是指针的解引用表达式，明确指向某个对象或者函数，所以也是lvalue
  • 如果某个函数的返回值是个左值引用，那么该函数调用的返回值也是lvalue.

rvalue,也就是没有明确的指向某个对象或者函数

  • a + b,value是编译器生成的临时对象，是rvalue
  • 10,字面值常量，没有明确的指向某个对象或者函数，是rvalue
  • int func(),函数的返回值不是引用类型，则函数调用的返回值是rvalue,没有明确的指向某个对象或者函数，value实际也是编译器自己生成的临时对象
c++11

c++11中，value catetory多了一堆东西，现在有glvalue，rvalue，lvalue,xvalue,prvalue

其关系如图，

也就是最终表达式的value category最终落在以下三者之一lvalue,xvalue,prvalue.

  • lvalue 其定义和c++11之前一样，is an expression whose evaluation determines the identity of an object or function

  • xvalue An xvalue (an “expiring” value)通常也明确的指向某个对象，但这个对象的生命周期快要到头了(so that its resources may be moved, for example). （从这个角度讲，xvalue属于c++11之前的lvalue的范畴） An xvalue is the result of certain kinds of expressions involving rvalue references. [Example: The result of calling a function whose return type is an rvalue reference is an xvalue.]也就是说，这样的Widget&& func(Widget&)函数，其调用返回值是xvalue. 事实上返回的rvalue reference很可能是明确的指向某个对象的，只不过这个对象near the end of its lifetime ，通常其资源很快就被移动到别的对象的。 虽然xvalue也明确的指向某个对象，但这个对象要被移动的，所以它并不能且不应该被左值引用关联，所以c++11对此搞出了右值引用。右值引用可以引用xvalue。（因为它并不能被左值引用，所以从这个角度讲，xvalue又有c++11之前的右值的属性）

  • glvalue A glvalue (“generalized” lvalue) is an lvalue or an xvalue.

  • rvalue 在c++11之前的rvalue的范畴之上再加上xvalue.

  • prvalue rvalue除去xvalue,也就是c++11之前的rvalue

再次看下那张图

我们在遇到xvalue时，都是把他当做右值的。只能被右值引用或者const坐值引用引用， 不能被非const左值引用引用。如下

const string&  getvariable( string&  a){
   return static_cast<string&&>(a);
}

string&&   getvariable( string&  a){
   return static_cast<string&&>(a);
}

可以编译通过，但是写成如下，编译不过

string&  getGlobal( string&  a){
   return static_cast<string&&>(a);
}

移动语义

c++11引入了移动语义，也就是对象的资源可以移动，从一个对象中移动到另一个对象中。也就是对象支持移动构造，移动赋值操作。 移动操作比拷贝操作要简单的多，比如string资源的移动，只需要将被移动对象的指针成员赋值给获取资源的对象，被移动对象的指针成员被重置即可。而如果是拷贝的话，则可能涉及复杂的分配内存,设置控制字段成员的操作。 vector也是如此，vector的拷贝构造是新创建一个vector,有自己的内存。而vector的移动，只需要获取被移动的vector的内存，也即是剥夺其指针的值。

拷贝构造，拷贝复制，其参数都是const左值引用。 移动构造，移动复制，其参数都是右值引用。通常引用的都是xvalue, 指向的对象的资源很快就被剥夺了。

我们如何告知编译器，某个对象的资源我们不再需要使用了，可以被移动了呢？c++11提供了std::move函数,其实现涉及到万能引用，见下章

template<typename T>
typename std::remove_reference<T>::type && move(T&&  t) noexcept {
    return static_cast<typename std::remove_reference<T>::type &&>(t);
}

关于static_cast<T>(v)返回值的value category如下： The result of the expression static_cast(v) is the result of converting the expression v to type T. If T is an lvalue reference type or an rvalue reference to function type, the result is an lvalue; if T is an rvalue reference to object type, the result is an xvalue; otherwise, the result is a prvalue. The static_cast operator shall not cast away constness

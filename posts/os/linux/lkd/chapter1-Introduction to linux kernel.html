chapter1-Introduction to linux kernel

Unix 历史

  • Bell Labs' Unix --> AT&T System V
  • BSD(Berkeley Software Distributions) --> Darwin,FreeBSB,NetBSD,OpenBSD
  • Unix商业版本,HP,IBM,Sun等公司开发的系统，要么基于AT&T,要么基于BSD

Unix系统特点

  • 简单 系统调用少，设计优雅
  • everything is file 对于各种设备，数据的操作简化为一系列核心的系统调用 open(),read(),write(),close()等
  • 内核和核心系统工具使用C语言编写 可移植性，C语言开发人员多
  • 进程创建时间快，提供独特的fork()系统调用
  • 提供简单和健壮的IPC primitives,结合进程创建时间快的特性，可创建多个简单的进程，每个进程 do one thing and do it well,多个 single-purpose 进程相互配合，完成复杂任务。

Unix系统支持的功能

  • 抢占式多任务，多线程
  • 虚拟内存
  • 按需分配页面
  • 按需加载共享库
  • tcp/ip networking

这些linux系统都支持

Unix 既可以在有上百个处理器的大型机器上运行，也可运行在嵌入式小型设备中。

Linux历史

  • 1991年，Linux Torvalds开发最早版本,运行在Inter 80386处理器上，并发布到网上
  • 获得很多开发者关注，共同贡献代码，衍生成社区合作项目
  • 直至今天，Linux系统成熟完备，可运行在多种底层体系架构中（Alpha,ARM,PowerPC,SPARC,x86-64）

Linux is a Unix-like sytem,but it is not Unix. 尽管Linux借鉴了很多Unix设计思想，实现了Unix API(defined by POSIX and the Single Unix Specification),但并不是直接在Unix源码上开发的。

Linux不是一个商业产品，而是通过网络社区合作开发的项目。Linux内核是开源的，licensed under GNU GPL(General Public License)version 2.0

Linux 系统包括内核，C库,toolchain, 基本的系统工具比如登录进程，shell.也可包括桌面系统比如GNOME，还有大量的免费或商业软件。当我们通常单单只提到Linux时，通常是指Linux内核。

通常操作系统包括内核，设备驱动程序，boot loader, command shell,user interface, basic file and system utilities. 通常内核由 interrupt handlers， processes scheduler,memory management system , system services such as networking and interprocess communication组成。

内核运行在内核空间中。内核空间（kernel space)通常指的是elevated system state(内核态)和受保护的内存空间。相比之下用户程序运行在user-space中。整个系统要么在内核空间中以内核态运行内核代码，要么在用户空间中以用户态运行用户进程。

当用户进程执行系统调用时，会进入内核态执行内核代码，这时我们称内核运行在 process context中。 当中断发生时，系统亦会进入内核态执行内核代码，这是我们称内核运行在 interrupt context中

Linux系统中，每个处理器任意时刻都会处于以下三种状态之一

  • 在用户空间中，执行用户进程的代码
  • 在内核空间中，在 process context 下，执行与系统调用相关的内核代码
  • 在内核空间中，在interrupt context下，执行与中断相关的内核代码

Linux Versus Unix

  • Linux支持模块的动态加载
  • Linux 支持SMP，部分传统的Unix不支持
  • Linux 内核是可抢占的。大部分Unix不支持
  • Linux 不区分线程和进程，对内核而言，这两者没有区别，只是线程共享了一些资源而已。
  • Linux提供面向对象的设备管理，比如实现了 device classes, hot-pluggable events, user-space device filesystem
  • Linux是免费的，社区合作项目。没有任何义务去实现以市场为导向的一次性需求。

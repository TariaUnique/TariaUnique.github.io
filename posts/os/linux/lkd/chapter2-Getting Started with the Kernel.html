chapter2-Getting Started with the Kernel

linux source tree directories

配置内核并编译

内核的很多features提供了配置选项，比如SMP支持，配置选项为CONFIG_SMP。

配置选项的大部分要么为yes or no， 要么为yes,no, module。 module表示为将该feature编译为模块，（单独的可连接目标文件）。

也有部分配置选项为strings or integers，作为预处理宏的值

内核提供的配置工具

  • make config 命令行工具，一个个配置选项的过一遍，用户给每个配置选项选择yes,no, moudle等
  • make menuconfig 图形工具
  • make gconfig 图形工具
  • make defconfig给相应的architecture提供默认的配置。

配置选项的值保存在source root 下的.config中。所以也可以直接在该文件中更改配置值。

build之前validate and update configuration，make oldconfig

配置完之后，make编译内核，或者make -jn可开启多任务并发编译，比如make -j32 > /dev/null

内核在编译后会在根目录下生成System.map文件，其中为符号和地址对照表，用于debugging时将内存地址翻译为函数和变量。

安装

安装内核取决于architecture and boot loader，比如对于x86系统，引导程序为grub而言，需要将 arch/i386/boot/bzImage(编译好的内核文件)拷贝到 /boot,重命名为vmlinuz-version,编辑 /boot/grub/grub.conf,给内核添加新的entry. 安装模块只需要执行make modules_install即可,这会将所有的模块安装到/lib/modules下。

开发内核时需要注意的点

  • No libc or Standard Headers 大部分libc functions内核都自己实现了，在/lib目录下。比如对于字符串函数，实现在/lib/string.c，只需要include 即可使用

  • 使用GNU C 拓展

    • inline funcion，比如： static inline void funcxx()
    • inline assembly,gcc编译拓展可将汇编指令插入到C函数中。这只在针对特定体系结构的内核代码中可使用。如下代码片段执行x86的rdtsc指令，获取tsc(timestamp resigter)的值
        unsigned int low,high;
  asm volatile("rdtsc" : "=a" (low), "=d" (high));
  /* low and high now contain the lower and upper 32-bits of the 64-bit tsc */

    • Branch Annotation gcc 编译器提供指令优化条件分支语句，可使用此类指令表明某个条件极有可能或者几乎没有可能会发生，编译器可根据此指令对条件分支语句做相应的编译优化。linux 将系列指令包装成易于使用的宏，比如：

        if(unlikely(condition)){

  }
  //or
  if(likely(condition)){

  }

  • No Memory Protection 当我们在用户进程中访问非法内存时，内核捕捉该错误，发送SIGSEGV信号，并kill该进程。而如果在内核中发生非法内存访问，result in oops 同时，内核使用的内存是无法被置换到磁盘的(reserved)，每多使用一点内存就意味着可用物理内存减少一点。

  • 内核中使用浮点运算很麻烦，需要trap自己，所以不要在内核代码中使用浮点运算
  • 进程在用户空间下可使用的栈空间是动态增长的，而在内核空间的栈是固定大小的，x86机子上，内核栈大小可配置,通常为2个page大小。
  • 同步和并发问题 linux内核是可抢占的，多任务的，smp支持的。同时中断也是异步的，随时可在内核访问临界资源时发生。 linux内核提供spinlock,semaphore等primitive来解决race conditon
  • 可移植性问题 linux内核是兼容多个体系结构的，除了架构独立的C代码外，对于特定架构的代码，应该独立放在单独的文件夹中。在编写内核代码时，需要注意一些规则，比如endian neutral, do not assume the word or page size等。

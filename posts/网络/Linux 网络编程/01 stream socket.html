01 stream socket

socket是操作系统提供的一个编程接口，它用来代表某个网络通信。应用程序通过socket来调用系统内核中处理网络协议的模块，而这些内核模块会负责具体的网络协议的实现。这样，我们可以让内核来实现网络协议的细节，而我们只需要提供所要传输的内容就可以了，内核会帮我们控制格式，并进一步向底层封装。

因此，在实际应用中，我们并不需要知道具体怎么构成一个UDP/TCP包，而只需要提供相关信息(比如IP地址，比如端口号，比如所要传输的信息)，操作系统协议栈会在传输之前会根据我们提供的相关信息构成一个合格的UDP/TCP包(以及下层的IP包和帧)

In Linux and Unix-like operating systems, sockets are categorized into several types based on their characteristics and the services they provide:

  • Stream Sockets (SOCK_STREAM): These provide reliable, two-way, connection-based byte streams. They use TCP (Transmission Control Protocol) for the internet address family. They ensure that data will arrive in the order it was sent and without any duplicates.

  • Datagram Sockets (SOCK_DGRAM): These provide a connectionless, unreliable service using UDP (User Datagram Protocol). They are used when you need to send small amounts of data quickly and don't mind if a few packets are lost along the way.

  • Raw Sockets (SOCK_RAW): These provide access to the underlying communication protocols, 允许程序直接发送和接收网络层的原始数据包，链路层的帧

  • UNIX Domain Sockets (AF_UNIX): These provide inter-process communication on the same machine and are identified by a file system path.

  • 等等其他不常见的，省略

接下来关于socket的使用实例以python3 socket库为例

python3 socket库中接口可能抛出的常见异常

  • socket.error: This is the base class for all exceptions raised by the socket module. It is actually just an alias for the built-in OSError exception in Python 3.

  • socket.herror: This is a subclass of socket.error/OSError that is raised for address-related errors by gethostbyname() and gethostbyaddr().

  • socket.gaierror: This is another subclass of socket.error/OSError that is raised for address-related errors by getaddrinfo() and getnameinfo().

  • socket.timeout: This is a subclass of socket.error/OSError that is raised when a timeout occurs on a socket which has had timeouts enabled via a prior call to settimeout().

  • all kinds of others errors, such as BlockingIOError, BrokenPipeError, ConnectionResetError,ConnectionRefusedError, etc. All are subclasses of socket.error/OSError

在非阻塞socket的方法中，我们需要重点关注error number等于EWOULDBLOCK,EAGAIN,EINPROGRESS的error,在python3 中，EWOULDBLOCK和EAGAIN是同一个值，代表同一个意思

  • EWOULDBLOCK / EAGAIN: The operation would block, but the socket is set to non-blocking mode. Most systems make EWOULDBLOCK and EAGAIN the same value, because they essentially mean the same thing.
  • EINPROGRESS: The operation (typically connect) on a non-blocking socket cannot complete immediately. You can use select, poll, etc on the socket with a write condition, and it will be ready when the connect completes.

Stream Sockets

Stream Sockets (SOCK_STREAM): These provide reliable, two-way, connection-based byte streams. They use TCP (Transmission Control Protocol) protocol for communication. They ensure that data will arrive in the order it was sent and without any duplicates.

simple tcp server

import socket
import threading

class ClientThread(threading.Thread):

    def __init__(self, client_address, client_socket):
        threading.Thread.__init__(self)
        self.csocket = client_socket
        self.caddress = client_address
        print("New connection added: ", self.caddress)


    def run(self):
            print("Connection from : ", self.caddress)
            while True:
                try:
                    data = self.csocket.recv(65536)
                    if not data:
                        #客户端关闭了连接
                        print("Client at ", self.caddress,  " disconnected...")
                        break
                    print("from client", data)
                    try:
                        self.csocket.sendall(data)
                    except socket.error as send_error:
                        print(f"Socket send error: {send_error}")
                        break
                #socket.recv()抛出异常
                except socket.error as recv_error:
                    print(f"Socket recv error: {recv_error}")
                    break
            self.csocket.close()

def start_server():
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.bind(('localhost', 12345))
    server.listen(1)
    print("Server started! Waiting for connections...")

    while True:
        client_sock, client_addr = server.accept()
        new_thread = ClientThread(client_addr, client_sock)
        new_thread.start()

if __name__ == "__main__":
    start_server()

socket.socket(socket.AF_INET, socket.SOCK_STREAM) 这个接口创建了SOCK_STREAM类型的socket,其使用的地址族是socket.AF_INET，也就是使用IPv4地址。如果我们需要使用IPv6地址，则使用socket.AF_INET6地址族

server.bind(('localhost', 12345)) 将套接字绑定到一个地址和端口上。端口号的范围从 0 到 65535，其中 0 到 1023 是保留端口号，用于众所周知的 services（如端口 80 用于 HTTP 服务）。你的服务器应该使用一个未被其他服务占用的端口号。当你调用 bind() 方法时，如果地址和端口已经被另一个套接字使用，或者你尝试绑定到一个特权端口号（小于 1024），而没有相应的权限，那么 bind() 方法将抛出一个 socket.error 异常。

server.listen(1) 这个方法告诉套接字开始监听传入的连接请求。参数1指的是 backlog,它表示在拒绝新的连接之前，操作系统可以挂起的最大连接数量。换句话说，这是在服务器处理完一个连接之前，可以排队等待接受的连接数量。如果队列已满，新的连接请求将被拒绝。在实际应用中，backlog 的设置应该基于服务器的预期负载和性能。如果预计会有大量并发连接，那么可以设置一个较高的 backlog 值，例如，Linux 系统的 backlog 上限是 128，而 FreeBSD 的上限是 511。但是，设置过高的 backlog 值可能会导致资源浪费，因为每个排队的连接都会占用一些内存资源。

client_sock, client_addr = server.accept() server.accept() 如果是阻塞socket,则这个方法会一直阻塞知道有链接请求过来，或者异常发生 如果是非阻塞socket,在调用这个方法时如果没有客户端请求，则会抛出BlockingIOError异常(也就是socket.error的子类型，其error number是EWOULDBLOCK / EAGAIN ,或者是EINPROGRRESS，后续这种异常都统一叫做BlockingIOError异常) 如果是非阻塞socket,我们通常将监听socket放入select的readable list中，可读时，表示有请求到来。

import socket
import select

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.setblocking(False)

# bind and listen
server.bind(('localhost', 12345))
server.listen(5)

inputs = [server]  # a list of all sockets that we'll check

while True:
    readable, writable, exceptional = select.select(inputs, [], [])
    for s in readable:
        if s is server:  # If the server socket is readable, it means a new connection is available
            connection, client_address = s.accept()
            connection.setblocking(False)
            inputs.append(connection)
        else:  # If a client socket is readable, it means the client has sent some data
            data = s.recv(1024)
            if data:
                print('received "{}" from {}'.format(data, s.getpeername()))
            else:  # If recv() returns with 0 the other end is closed
                inputs.remove(s)
                s.close()

socket.recv(65536) 这个接口从套接字接收数据，参数是接收缓冲区的大小(注意是用户空间缓冲区，而不是内核tcp socket的接受缓冲区)，65536(2^16)是可被设置的最大值。这个值应该根据你的应用程序需求来设置，以确保它不会导致内存不足或其他性能问题。 如果客户端关闭了连接，则socket.recv()接口会返回空data。 在阻塞模式下，这个接口会一直阻塞直到有数据可读，或者抛出socket.error异常，比如connection broken. 在非阻塞模式下，在没有数据可读时，会抛出BlockingIOError异常

socket.send(msg) 这个接口在成功的情况下，会返回已发送的字节数，可能小于提供的字节数。 如果是阻塞模式，and the data cannot be sent immediately, it will block until at least one byte of the data is sent or an error occurs(比如链接关闭，网络问题等等异常) 如果是非阻塞模式，and the data cannot be sent immediately, it will raise a BlockingIOError.

simple tcp client

import socket
import sys

def start_client():
    client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    try:
        client.connect(('localhost', 12345))
        print("Connection established.")
    except socket.error as e:
        print(f"Error: {e}")
        sys.exit()
    else:
        try:
            client.sendall(b'A'*100)
            client.recv(65536)
        except socket.error as error:
            print(f"Socket  error: {error}")
        client.close()

if __name__ == "__main__":
    start_client()

client.connect() 在阻塞模式下， the method will block until the connection is made, or an error occurs. If the connection is successful, the method just returns and you can start sending/receiving data. If there is an error, an exception is raised. 在非阻塞模式下，if the connection could be completed immediately (e.g., when connecting to a localhost), the method will succeed.Otherwise, it will raise a socket.error with error number of EINPROGRESS . Then you need to use select.select() to wait for the socket to become writable, which indicates that the connection has completed.

非阻塞连接示例：

import socket
import select
import errno
import sys

def connect_non_blocking(server_ip, server_port):
    server_address = (server_ip, server_port)

    # Create a TCP/IP socket
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

    # Set the socket to non-blocking
    sock.setblocking(0)

    try:
        # Connect to the server
        sock.connect(server_address)
    except socket.error as e:
        if e.errno != errno.EINPROGRESS:
            print(f"Error: {e}")
            sys.exit()

    while True:
        try:
            # Wait for the socket to be writable
            _, writable, exceptional = select.select([], [sock], [sock])

            if sock in writable:
                print("Socket is writable, connection established.")
                break

            if sock in exceptional:
                print("Connection failed.")
                sys.exit()

        except socket.error as e:
            print(f"Error: {e}")
            sys.exit()

    return sock
# Use the function
sock = connect_non_blocking('localhost', 12345)

The select.select() function is used to monitor changes to a set of sockets and block until at least one socket is ready for some kind of I/O operation (like reading or writing), or exception happens to some sockets, or timeout.

The function takes three lists as arguments:

  • The first list contains the sockets that should be checked for incoming data to be read.
  • The second list contains the sockets that will be checked for whether they are ready to send data.
  • The third list contains the sockets that will be checked for whether they have any exceptions.

The select.select() function returns three lists:

  • A list of sockets that are ready to be read.
  • A list of sockets that are ready to send data.
  • A list of sockets that have exceptions.

So, if the sock socket is in the write_sockets list, it means that the socket is now writable, and the connection has completed.

select()最后还可以传入一个时间参数，表示等待多久的时间，如果timeout,没有任何readable,writeable,exception事件发生，则返回三个空list。如果没有传入时间参数，表示一直等待，直到有事件发生。如果传入0，则不会等待，只检查有没有事件发生

如下

import socket
import select
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
readable, writable, exceptional = select.select([sock], [sock], [sock], 0.5)
print(readable, writable, exceptional)  # Prints: [] [] []

import socket
import select
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
#block indefinitely
readable, writable, exceptional = select.select([sock], [sock], [sock])

对于发生异常的socket,也就是select中exception list返回的socket,如果我们需要处理这个异常，是需要通过一个IO操作来trigger这个异常的。

#......
        try:
            readable, writeable, exceptional = select.select(readlist,writelist,exceptionlist)

            for s in exceptional:
                try:
                    # Try to receive some data to get the error
                    sock.recv(1)
                except socket.error as e:
                    print(f"socket error : {e}")
                if s in readlist:
                    readlist.remove(s)
                if s in writelist:
                    writelist.remove(s)
                if s in exceptionlist:
                    exceptionlist.remove(s)
                s.close()

        except socket.error as e:
            print(f"Error: {e}")
            sys.exit()

这里如果发生了异常，这个异常需要通过下一次的IO操作才能触发。
